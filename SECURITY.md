# Security and responsible use

Little Voyages is a static, client-side website hosted on GitHub Pages. Its published files and cruise exports are public. Do not place passwords, API keys, booking references, identity documents, or private passenger information in the repository or exported logbooks.

No permission is granted to gain unauthorized access, bypass controls, exploit the live site or hosting platform, compromise accounts, extract private information, modify files without authorization, or disrupt service. This is not a bug-bounty program or an invitation to scan or attack infrastructure. Obtain the owner's explicit permission before active security testing, and respect GitHub's rules for its services.

## Reporting a concern

Use the [repository's Security tab](https://github.com/dev1niscool/little-voyages/security) to report a vulnerability privately if GitHub's private reporting option is available. If it is unavailable, use the owner's published contact channel. If no private channel is available, open a minimal, nonsensitive [issue](https://github.com/dev1niscool/little-voyages/issues) requesting a private reporting channel.

Do not put secrets, private passenger data, working exploits, or sensitive vulnerability details in a public issue. Share a description, affected version or URL, and safe reproduction steps privately once a channel is agreed. Do not continue testing after encountering private information or disruption.

The [AI-use policy](AI-USAGE.md), crawler preferences, and page metadata express permissions. They do not add authentication, encryption, firewall rules, or protection against hacking.
